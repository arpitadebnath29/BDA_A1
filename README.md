**Arpita Debnath | MT25018**

MapReduce vs Apache Spark vs DuckDB, using NYC Yellow Taxi data (Jan 2026).

## Required Software

- Python 3.11 (PySpark 4.x doesn't support very new Python versions -- use
  3.11 explicitly, not whatever `python3` defaults to)
- Java 17 or newer (PySpark 4.x requires JDK 17+ -- Spark 4.0 dropped
  support for Java 8/11; this project used Java 17.0.12)
- DuckDB CLI (`brew install duckdb` on macOS)
- pip packages: `mrjob`, `pyspark`, `duckdb`, `matplotlib`

## Installation

```bash
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
java -version   # confirm Java is installed
```

`venv/` itself is not included in the submission -- it is large (600+ MB)
and tied to this specific Mac (hardcoded paths, compiled binaries for
Apple Silicon macOS). `requirements.txt` is the portable way to recreate
a working environment on any machine.

## Setup (once)

```bash
cd data
duckdb < ../data_prep/prepare_data.sql
cd ..
python data_prep/verify_row_counts.py   # expect 100000/500000/1000000/2000000
```

Machine specs (CPU, RAM, storage, GPU) are already filled into `MACHINE_INFO`
at the top of `scripts/machine_info.py` -- update those values by hand if
running on a different machine.

## Running Everything

Run each task's commands in order (any order works, since each script
appends to `results/timings.csv` independently):

```bash
# Task 1
python mapreduce/task1.py data/taxi_1m.csv
python spark/task1.py --input data/taxi_1m.csv --output /tmp/task1_spark_out
duckdb -c ".read duckdb/task1.sql"
python scripts/task1_timing_run.py --student-id MT25018 --input data/taxi_1m.csv

# Task 2
python spark/task2.py --student-id MT25018 --input data/taxi_2m.parquet
python scripts/task2_duckdb_run.py --student-id MT25018 --input data/taxi_2m.parquet

# Task 3
python spark/task3.py --student-id MT25018 --trips data/taxi_2m.parquet --zones data/taxi_zone_lookup.csv
python scripts/task3_duckdb_run.py --student-id MT25018 --trips data/taxi_2m.parquet --zones data/taxi_zone_lookup.csv
```
